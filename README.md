# ClaudeGame002
Claude試作2号 — **きゅうりの国の女神さま**（きゅうり育成ゲーム）

ブラウザだけで遊べる、のんびり放置系のきゅうり育成ゲームです。

## あそびかた
1. 🔔 女神さまのそばに、国の住民の女の子たちが集まってきます。
2. ✨ 「まほうをかける」で、女神さまが女の子をきゅうりに変えます（魔法は**必ず女神さまが手動で**かけます）。
3. 💧🌿 じょうろ／ひりょうを選んで畑をタップ（なぞってもOK）。水がないと育たず、肥料があると早く育ちます。
4. ✨ 育ったきゅうりをタップで収穫 → 「しあわせ！」
5. 🍲 かごのきゅうりを**丸ごとそのまま**大鍋へ。ピクルスになり、しあわせメーターがたまります。
6. 🏰 しあわせメーターの**累計**で施設を建設・レベルアップ（メーターは減りません）。

## 施設（13種類・レベル上限なしのものも）
| 施設 | 効果 |
|---|---|
| 🌱 ひろがる畑 | 畑のマスが増える |
| 🔔 よびよせの鐘 | 住民を女神さまの近くに自動で集める（人数・速さUP） |
| ☁️ あまぐもさん | 自動水やり |
| 🍄 キノコの肥料工房 | 自動肥料 |
| 🏡 星のガラス温室 | 成長スピードUP |
| 🌈 虹の水路 | 水・肥料が長持ち |
| 🐰 収穫うさぎ小屋 | 自動収穫 |
| 🦋 ちょうちょ便 | かごから大鍋へ自動で運ぶ |
| 🪄 星のステッキ | ひとふりで魔法をかけられる人数UP（魔法自体は手動） |
| 🌙 三日月ランプ | ★4のきらきらきゅうりが育ちやすい |
| 🍲 大鍋のおまじない | しあわせ倍率UP |
| ⛲ ハートの噴水 | ときどき「だいしあわせ」(3倍) |
| 🏰 きゅうり城 | 国全体のしあわせ倍率UP |

データはブラウザ（localStorage）に自動保存され、ページを閉じている間も施設が最大8時間ぶん働きます。

## GitHub Pages で公開する
ビルド不要の静的ファイル（`index.html` / `style.css` / `game.js` / `assets/`）だけで動きます。

1. リポジトリの **Settings → Pages** を開く
2. **Build and deployment → Source** を「Deploy from a branch」に
3. **Branch** で公開したいブランチ（例: `main`）と `/ (root)` を選んで **Save**
4. 数分後に `https://<ユーザー名>.github.io/ClaudeGame002/` で遊べます

ローカルで試す場合は、このフォルダで `npx http-server` などを起動して開いてください。
